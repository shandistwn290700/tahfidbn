Silakan hubungkan ke WiFi server

Server () tidak bisa dijangkau. Pastikan HP ini terhubung ke WiFi sekolah yang sama dengan server, lalu coba lagi.

Alamat Server Tahfid

Masukkan alamat server sekolah, contoh: 192.168.1.10:3000. Tanyakan ke penanggung jawab Tahfid bila belum tahu alamatnya.
